# Grilling Protocol

Relentlessly interview the user or peer agents to reach alignment on architectural decisions.

Work in rounds across the **decision frontier** (questions ready to ask without guessing unconfirmed answers).

Format questions cleanly:
```
❓ **Q1** - **<title>**: <context and options>
➡️ <recommended answer>
```
Word each question so selecting the recommendation requires minimal confirmation.
